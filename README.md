# ResumeBuilder - Free Open Source Resume Builder

A modern, free, and open-source resume builder with 15+ professional templates. Build beautiful resumes without sign-up and export to PDF or Word instantly.

## ✨ Features

- 🎨 **15+ Professional Templates** - From classic to modern, find the perfect style
- 📄 **Export to PDF & Word** - Download in multiple formats with one click
- 👁️ **Live Preview** - See changes in real-time as you build
- 🎨 **Customizable Colors** - Match your personal brand
- 💾 **No Sign-up Required** - Start building immediately
- 🚀 **Fast & Responsive** - Built with React and Tailwind CSS
- 🔒 **Privacy First** - All data stays in your browser
- 💯 **100% Free** - No hidden costs or premium features

## 🚀 Getting Started

### Prerequisites

- Node.js 16+ and npm

### Installation

1. Clone the repository
```bash
git clone https://github.com/opensourcekingprojects/resumebuilder.git
cd resumebuilder
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 🏗️ Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## 📦 Tech Stack

- **React 18** - UI library
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Router** - Navigation
- **html2canvas** - PDF generation
- **jsPDF** - PDF export
- **docx** - Word document export
- **Vite** - Build tool
